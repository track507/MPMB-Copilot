# Custom Docs Policy

## Purpose

This project supports optional retrieval-augmented generation (RAG) over custom reference materials provided by end users.

## What this project provides

- Tooling to index and retrieve user-provided context.
- No default third-party documentation corpus is bundled in this repository for redistribution.

## User responsibility

By using custom document ingestion, the user/operator is responsible for ensuring they have sufficient rights to:

1. Upload or copy the documents.
2. Process them for indexing/chunking/embedding.
3. Use retrieved excerpts in generated responses.
4. Redistribute or host any derived data where applicable.

## Prohibited usage

Users must not upload or index content when contractual terms, website terms, license terms, or applicable law prohibit that processing (including AI/ML-related restrictions where present).

## Data handling expectations

- Custom docs are treated as user-provided context.
- This project does not claim ownership of third-party uploaded materials.
- Users should remove content they cannot lawfully process.

## No legal advice

This policy is a technical and operational guideline, not legal advice. Users should consult qualified counsel for legal determinations.
