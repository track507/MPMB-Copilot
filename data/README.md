# Data Directory

This directory contains local data files that are NOT committed to git.

## Structure

- **mpmb_source/** - Local clone of the MPMB main repository (`master` / 2014)
  - Managed by `pnpm run setup`
  - Not committed (external source dependency)

- **mpmb_source_2024/** - Local clone of the MPMB 2024 repository (`main`)
  - Managed by `pnpm run setup`
  - Not committed (external source dependency)

- **imports_source/** - Local clone of the safety-orange Imports repository
  - Managed by `pnpm run setup`
  - Not committed (external source dependency)

- **chunked_output/** - Generated chunks from `chunk_mpmb.py`
  - JSON files the indexer embeds into Qdrant, and the corpus `mpmb_search` queries
  - Generated by `pnpm run setup`, which runs the analyzer and then `scripts/chunk_mpmb.py`

- **models/** - Durable ONNX cache for the local embedding and reranker models
  - Lives here rather than the OS temp dir so a Windows temp cleanup cannot break retrieval
  - Re-downloaded automatically if deleted

- **settings.json** - Hot-reloaded behavioral settings (`PATCH /api/settings` writes here)
  - `pnpm run setup` writes `inference_device` on a first run if it detects a GPU; an
    existing value is never overwritten

- **uploads/** - Scoped user uploads (`session/`, `global/`, `shared/`)
  - The Postgres registry is the source of truth; these are the canonical bytes

- **index_cache/** - Cached embeddings
  - Vector embeddings for faster indexing
  - Regenerate when needed

- **intent_examples.json** - Seed phrases the intent classifier builds its centroids from

## Setup

Bootstrapped from the repo root. The setup script is cross-platform Node - no PowerShell required.

```bash
pnpm run setup
```

What the script does:

1. Creates `.env` from `.env.example` when missing, pointing Postgres/Qdrant at the host
2. Installs the backend Python dependencies with `uv sync --locked`
3. Reports the ONNX execution provider and, on a first run, opts into GPU inference
4. Clones or updates the three source repositories above
5. Runs the source analyzer, then the chunker, writing JSON into `chunked_output/`

Useful flags: `--skip-dependencies` reuses the existing `backend/.venv`; `--dry-run`
reports what would change without touching anything.

The setup script does not start Docker or run indexing. It is only responsible for
environment preparation, source acquisition, and chunk generation. `pnpm run setup:all`
chains it with `setup:services` (postgres + qdrant) and `setup:index`.

## Notes

- Placeholder files such as `.gitkeep` may exist in these folders so the directory structure can be committed. The setup script removes those placeholders when it needs to clone a repo into that folder.
- Source and output locations can be overridden through `.env` values such as `MPMB_SOURCE_DIR`, `MPMB_SOURCE_2024_DIR`, `IMPORTS_SOURCE_DIR`, and `CHUNKED_OUTPUT_DIR`.
- Source repository defaults can be overridden with `MPMB_REPO_URL`, `MPMB_REPO_2024_URL`, `MPMB_REPO_BRANCH_2014`, `MPMB_REPO_BRANCH_2024`, and `IMPORTS_REPO_URL`.
