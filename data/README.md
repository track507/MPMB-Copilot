# Data Directory

This directory contains local data files that are NOT committed to git.

## Structure

- **mpmb_source/** - Local clone of the MPMB main repository (`master` / 2014)
  - Managed by `scripts/setup.ps1`
  - Not committed (external source dependency)

- **mpmb_source_2024/** - Local clone of the MPMB main repository (`dnd2024`)
  - Managed by `scripts/setup.ps1`
  - Not committed (external source dependency)

- **imports_source/** - Local clone of the safety-orange Imports repository
  - Managed by `scripts/setup.ps1`
  - Not committed (external source dependency)

- **chunked_output/** - Generated chunks from ``chunk_mpmb.py``
  - JSON files with code chunks for RAG indexing
  - Generated by `scripts/setup.ps1`, which then runs `scripts/chunk_mpmb.py`

- **adobe_docs/** - Adobe JavaScript documentation
  - Downloaded from the official Adobe Acrobat SDK docs site by `scripts/setup.ps1`
  - Includes the current Acrobat JavaScript Developer Guide, JavaScript API Reference, and related PDF spec files
  - Not committed (can re-download)

- **index_cache/** - Cached embeddings
  - Vector embeddings for faster indexing
  - Regenerate when needed

## Setup

This directory is now bootstrapped by the PowerShell setup script from the repo root.

```powershell
.\scripts\setup.ps1
```

What the script does:

- Clones or updates `mpmb_source/`
- Clones or updates `mpmb_source_2024/`
- Clones or updates `imports_source/`
- Downloads official Acrobat JavaScript docs into `adobe_docs/`
- Runs `scripts/chunk_mpmb.py`

The setup script does not start Docker or run indexing. It is only responsible for source acquisition and chunk generation.

## Notes

- Placeholder files such as `.gitkeep` may exist in these folders so the directory structure can be committed. `scripts/setup.ps1` will remove those placeholders when it needs to clone a repo into that folder.
- Source and output locations can be overridden through `.env` values such as `MPMB_SOURCE_DIR`, `MPMB_SOURCE_2024_DIR`, `IMPORTS_SOURCE_DIR`, `ADOBE_DOCS_DIR`, and `CHUNKED_OUTPUT_DIR`.
